🤖 EnterpriseAI API

Developer Documentation

📘 Introduction

EnterpriseAI provides an authenticated API that allows applications to communicate with the EnterpriseAI platform using a secure API key.

API authentication is performed using the X-API-Key request header.

🔐 Authentication

Every protected API request must include a valid EnterpriseAI API key. 

X-API-Key: EAI-YOUR-API-KEY
Never share your API key publicly or expose it in client-side source code.

🔑 Generate API Key

POST /api/generate-key

Generates a new EnterpriseAI API key for the currently authenticated user. 

POST /api/generate-key

Example Response

{
    "success": true,
    "api_key": "EAI-xxxxxxxxxxxxxxxx"
}

🧪 Test API

GET /api/test

Checks whether the supplied API key is valid and confirms that the EnterpriseAI API is working. 

fetch("/api/test", {
    method: "GET",
    headers: {
        "X-API-Key": "EAI-YOUR-API-KEY"
    }
})
.then(response => response.json())
.then(data => console.log(data));

Successful Response

{
    "success": true,
    "message": "EnterpriseAI API is working"
}

💬 Chat API

POST /api/chat

Sends a message to the EnterpriseAI backend and returns the generated AI response.

Request 

fetch("/api/chat", {
    method: "POST",
    headers: {
        "Content-Type": "application/json",
        "X-API-Key": "EAI-YOUR-API-KEY"
    },
    body: JSON.stringify({
        message: "Say hello"
    })
})
.then(response => response.json())
.then(data => console.log(data));

Successful Response

{
    "success": true,
    "reply": "Hello! How can I help you?"
}

⚠️ Error Responses

Missing API Key

{
    "success": false,
    "message": "API key required"
}

Invalid API Key 

{
    "success": false,
    "message": "Invalid API key"
}
